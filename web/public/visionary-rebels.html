Architecture

Seven Services.
One System.

Dhaba Orders is a restaurant ordering platform built across five stateless and two stateful services, each running in its own container on Kubernetes.

Stateless
web
The ordering page, kitchen screen and live stats panel. React app built inside Docker and served by Nginx. One image works in every environment.
React Vite Nginx
Stateless
menu-api
Reads the restaurant menu from Postgres and caches it in Redis for fast repeated access. Runs with Gunicorn, not the development server.
Python FastAPI Redis
Stateless
orders-api
Saves customer orders in Postgres and puts processing jobs on the Redis queue. /info shows the version and which pod answered the request.
Go Postgres Redis Queue
No web port
kitchen-worker
Background worker that takes jobs off the Redis queue and updates each order's status in Postgres from new to cooking to ready.
Java Spring Boot JRE
Stateless
stats-api
Serves live numbers from Redis: orders per minute and top dishes of the day. PHP-FPM with production settings and no debug mode.
PHP Laravel PHP-FPM
Stateful
postgres
Primary database for orders and the menu. Runs as a Kubernetes StatefulSet with a persistent volume, so no data is lost when the pod restarts or moves.
PostgreSQL PersistentVolume StatefulSet
Stateful
redis
Cache and job queue. Append-only file is switched on so queued jobs survive a pod restart. Also stores menu cache and live stats counters.
Redis AOF PersistentVolume

CI / CD

Code to Production
in One Pipeline.

Every merge to main runs the full pipeline automatically. Production only deploys after a teammate approves.

1
Static Analysis
ESLint, Ruff, golangci-lint, PHPStan, Checkstyle, hadolint, shellcheck
2
Unit Tests
Vitest, pytest, go test, JUnit, PHPUnit run in parallel
3
Build + Push
Changed images built, scanned for vulnerabilities and pushed to AWS ECR tagged by commit SHA
4a
Staging Deploy
Auto-deploy to staging. Smoke tests run. Automatic rollback if they fail.
4b
Production
Waits for teammate approval. Same images. Smoke tests. Auto rollback. Slack alert for every outcome.
